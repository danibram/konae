Limits

The numbers a Capsule and a Deployment run into. Both the Gate and the Kernel enforce the declaration limits. The Kernel alone enforces the runtime ones.

These figures come from docs/mcp.md and CONTEXT.md. When a number matters to a decision, read the section there.

Declarations

LimitValue
Actions per project100
Action nameLowercase dotted words, at most 100 characters
StatementOne statement, at most 20,000 bytes
Bindings per actionAt most 100
String input maxLength1 to 100,000
Guard message1 to 200 characters on one line
Schedule every5m to 24h
Schedule dailyA UTC time, 00:00 to 23:59
HTTP route pathAt most 200 characters
Allowlist entriesAt most 100

Queries

LimitValue
RowsA top-level LIMIT, or one row, and a 1000-row cap
Response size2 MiB
Statement time2 seconds, checked between SQLite steps
LIKE or GLOB pattern500 bytes
App database256 MiB

Requests and rates

LimitValue
Route request body64 KiB
Route calls without a key or session30 per 10 seconds per client address
Route calls with a user or key120 per 10 seconds per user or key, shared with actions_invoke
Signature clock window300 seconds
Replay window for one signature600 seconds
App login and signup10 attempts per minute per client address, 5 per minute for one email from one client address

Files

LimitValue
One file2 MiB
Deployment file quota20 MiB, the sum of the files it holds
Files per Deployment10,000
File nameFirst 180 characters kept

Invitations and credentials

LimitValue
Emails per app_invitations_create1 to 50
Invitation linkSeven days
littlebox login token24 hours
OAuth tokenOne hour, no refresh token

Transfers and publishing

LimitValue
Transfer chunkAt most 64 KiB, base64
Owner transfersExpire after one hour, eight at a time per owner
App user transfersExpire after 10 minutes, two at a time per app user
Administrative transferUp to 32 MiB, or a package component's limit
Publishing payloadMust fit in 26 MB, with its artifact in 16 MiB

Usage store

The store keeps 400 days and at most 100,000 rows of totals, the newest 50,000 Signals and the newest 10,000 scheduled runs. A string property keeps its first 128 bytes.
