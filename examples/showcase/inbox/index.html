    How events arrive

    Services post JSON to POST /hooks/events on this app's host, signed in the X-Inbox-Signature header as t=<unix seconds>,n=<nonce>,v1=<HMAC-SHA256> with the inbox's signing secret, over t, the nonce, the method, the path, the query string and the body, one per line. The body is { "source", "id", "severity", "title", "body"? }, and severity is info, warning or critical. A repeated source and id is stored once.

    Programs read GET /api/events?after=<id> with an API key the owner issued, sent as Authorization: Bearer.
